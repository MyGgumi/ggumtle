# 1주차

## 0. 기초 학습
- **Unity 네트워크 강의 수강**: 멀티플레이어 게임 개발을 위한 네트워크 통신 기초 이론 학습
- **DotNetty 프레임워크 학습**: 고성능 네트워크 통신을 위한 비동기 I/O 프레임워크 이해
- **게임 서버 및 클라이언트 원리 학습**: 배틀그라운드, 발로란트, MMORPG 등 다양한 사례를 보며 서버 원리 이해

## 1. 클라이언트-서버 통신 시스템 구해

### 1.1 DotNetty 기반 네트워크 통신 구현
- **패킷 시스템 설계**: 클라이언트-서버 간 데이터 교환을 위한 패킷 구조 설계
- **DotNetty 파이프라인 구성**: 인코더/디코더를 통한 안정적인 데이터 전송 구현
- **인증 시스템**: 사용자 토큰 검증 및 세션 관리 로직 구현
- **방 입장 시스템**: 멀티플레이어 방 참여 및 상태 관리
- **씬 전환 시스템**: 게임 상태에 따른 씬 전환 및 동기화

### 1.2 아키텍처 개선 및 최적화
- **라우터 시스템 도입**: 이벤트 기반에서 중앙집중식 패킷 라우팅으로 전환
- **IL2CPP 호환성**: Unity 빌드 최적화를 위한 코드 구조 개선
- **비동기 처리**: Thread.Sleep을 Coroutine으로 대체하여 UI 응답성 향상
- **멀티스레드 안전성**: MainThreadDispatcher 구현으로 Unity API 호출 안정성 확보

## 2. 네트워크 아키텍처 고도화

### 2.1 패킷 처리 시스템
- **Router 클래스 구현**: 패킷 타입별 핸들러 등록 및 자동 라우팅
- **패킷 타입 확장**: 게임 로직에 필요한 11, 20, 30, 31, 40, 41번 패킷 추가
- **직렬화 최적화**: DotNetty Unpooled 사용으로 메모리 효율성 개선
- **버퍼 관리**: try-finally 패턴으로 안전한 리소스 해제 보장

## 3. 게임 로직 구현

### 3.1 플레이어 관리 시스템
- **플레이어 초기화**: 31번 패킷을 통한 플레이어 정보 수신 및 처리
- **캐릭터 스폰**: Alien 모델을 활용한 플레이어 캐릭터 생성 시스템
- **상태별 시각화**: IsMongging 상태에 따른 색상 구분 (파란색/빨간색)

### 3.2 게임플레이 시스템
- **이동 시스템**: WASD 키를 통한 플레이어 이동 구현
- **카메라 시스템**: 로컬 플레이어 추적 카메라 구현
- **실시간 동기화**: 40/41번 패킷을 통한 플레이어 위치 실시간 동기화
