## D103 1주차 개발 진행상황 (sub1) - 공연경

### 인증/인가
** Google OAuth 로그인 연동 **

- 외부 OAuth 인증 서버와 연동하여 로그인 기능 구현
- 회원가입 & JWT 토큰 기반 인증 기능
- 최초 로그인 시 회원가입 처리
- Access / Refresh Token 발급 및 인증 처리

** 친구 기능 API **

- 친구 요청 API – 다른 사용자에게 친구 요청 생성
- 친구 요청 조회 API – 내가 보낸/받은 요청 확인 가능
- 친구 수락 API – 요청 수락 시 양방향 친구 관계 생성
- 친구 목록 조회 API – 나와 연결된 친구 목록 반환
- 친구 거절 API – 받은 요청 거절 처리
- 친구 검색 API – 닉네임 기반 친구 검색 기능
