# 1주차

## 0. 기초 학습
- FPS와 MMORPG 등의 실시간 멀티플레이 게임 서버의 역할과 구현 원리 학습

## 1. API 서버의 로비 기능 구현

- API 서버의 웹 소켓 통신을 위한 패킷 구조와 디스패처 설계 및 구현

- API 서버의 파티 생성, 초대, 초대 수락, 게임 시작 API 구현

- Redis에 파티 정보 캐싱 및 플레이어 매칭 시스템 구현

- Redis Pub/Sub 기반으로 게임 서버와의 메시징 구현

## 2. 게임 서버 구현

- 게임 서버의 Netty를 통한 소켓 통신을 위한 패킷 디스패처 고도화

- 게임 방 생성과 사용자 접속, 게임 시작 관리 로직 구현

- 동시성 보장 자료구조와 synchronize를 통해 멀티쓰레드 환경에서 안정적인 자원 사용용

- 사용자의 이동과 술래의 타격 전파 구현
